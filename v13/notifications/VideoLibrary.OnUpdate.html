VideoLibrary

VideoLibrary.OnUpdate

A video item has been updated.

Transport: WebSocket / TCP only

Server-initiated push message; it is never delivered over HTTP and carries no id member.

Message

{
  "jsonrpc": "2.0",
  "method": "VideoLibrary.OnUpdate",
  "params": {
    "sender": "<string>",
    "data": "<{id, type, playcount, transaction, added}>"
  }
}
