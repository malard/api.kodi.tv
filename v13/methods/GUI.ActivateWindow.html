GUI.ActivateWindow

Activates the given window

Permission: ControlGUI Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "GUI.ActivateWindow",
  "params": {
    "window": "<GUI.Window>",
    "parameters": "<array of string>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
windowGUI.WindowYes
parametersarray of string (minLength: 1) (minItems: 1)No

Returns

string

Errors
