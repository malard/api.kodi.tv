Input.SendText

Send a generic (unicode) text

Permission: Navigate Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Input.SendText",
  "params": {
    "text": "<string>",
    "done": "<boolean>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
textstringYesUnicode text
donebooleanNotrueWhether this is the whole input or not (closes an open input dialog if true).

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
