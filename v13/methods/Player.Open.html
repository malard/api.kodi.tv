Player

Player.Open

Start playback of either the playlist with the given ID, a slideshow with the pictures from the given directory or a single file or an item from the database.

Permission: ControlPlayback Transport: Response

Request

Start playback of a movie from the video library

{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "Player.Open",
  "params": {
    "item": {
      "movieid": 42
    }
  }
}

Response

{
  "jsonrpc": "2.0",
  "id": 3,
  "result": "OK"
}

Parameters
