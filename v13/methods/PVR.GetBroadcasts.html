PVR.GetBroadcasts

Retrieves the program of a specific channel

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "PVR.GetBroadcasts",
  "params": {
    "channelid": "<Library.Id>",
    "properties": "<PVR.Fields.Broadcast>",
    "limits": "<List.Limits>"
  }
}
