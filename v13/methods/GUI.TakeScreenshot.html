GUI

GUI.TakeScreenshot

Takes a screenshot into the configured screenshot folder

Permission: ControlGUI Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "GUI.TakeScreenshot",
  "params": {
    "content": "<\"composite\" | \"video\" | \"both\">"
  }
}

Parameters

NameTypeRequiredDefaultDescription
content"composite" | "video" | "both"No"composite"composite captures the full display output, video only the video frame, both writes two files, the video frame and the full composite, from the same rendered frame. Files are written asynchronously; the method acknowledges the request and does not wait for the write.

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
