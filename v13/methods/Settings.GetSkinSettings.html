Settings.GetSkinSettings

Retrieves all skin settings of the currently used skin

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Settings.GetSkinSettings"
}

Returns

NameTypeRequiredDefaultDescription
skinstring (minLength: 1)Yes
settingsarray of object {id, type, value}No

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
