PVR

PVR.GetPlayableBroadcasts

Retrieves the playable broadcasts of a specific channel within a time range

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "PVR.GetPlayableBroadcasts",
  "params": {
    "channelid": "<Library.Id>",
    "starttime": "<string>",
    "endtime": "<string>",
    "limits": "<List.Limits>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
channelidLibrary.IdYes
starttimestringYesstart of the time range, in the same format as PVR.Details.Broadcast.starttime
endtimestringYesend of the time range, in the same format as PVR.Details.Broadcast.endtime
limitsList.LimitsNobounds the broadcasts examined, not the ids returned

Returns

NameTypeRequiredDefaultDescription
limitsList.LimitsReturnedYes
broadcastidsarray of Library.IdYes

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
