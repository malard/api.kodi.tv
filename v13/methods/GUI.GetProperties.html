GUI.GetProperties

Retrieves the values of the given properties

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "GUI.GetProperties",
  "params": {
    "properties": "<array of GUI.Property.Name>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
propertiesarray of GUI.Property.Name (unique items)Yes

Returns

GUI.Property.Value

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
