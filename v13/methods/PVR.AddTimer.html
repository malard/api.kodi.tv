PVR

PVR.AddTimer

Adds a timer to record the given show one times or a timer rule to record all showings of the given show or adds a reminder timer or reminder timer rule

Permission: ControlPVR Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "PVR.AddTimer",
  "params": {
    "broadcastid": "<Library.Id>",
    "timerrule": "<boolean>",
    "reminder": "<boolean>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
broadcastidLibrary.IdYesthe broadcast id of the item to record
timerrulebooleanNofalsecontrols whether to create a timer rule or a onetime timer
reminderbooleanNofalsecontrols whether to create a reminder timer or a recording timer

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
