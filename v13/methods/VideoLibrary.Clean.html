VideoLibrary.Clean

Cleans the video library for non-existent items

Permission: RemoveData Transport: Response

Request

  "id": 1,
  "method": "VideoLibrary.Clean",
  "params": {
    "showdialogs": "<boolean>",
    "content": "<\"video\" | \"movies\" | \"tvshows\" | \"musicvideos\">",
    "directory": "<string>"
  }
}
