Application

Application.SetVolume

Set the current volume

Permission: ControlPlayback Transport: Response

Request

Set the application volume to an absolute level

{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "Application.SetVolume",
  "params": {
    "volume": 75
  }
}

Response

{
  "jsonrpc": "2.0",
  "id": 4,
  "result": 75
}

Parameters

NameTypeRequiredDefaultDescription
volumeinteger (minimum: 0; maximum: 100) | Global.IncrementDecrementYes

Returns

integer

Errors
