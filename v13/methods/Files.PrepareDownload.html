Files.PrepareDownload

Provides a way to download a given file (e.g. providing an URL to the real file location)

Permission: ReadData Transport: Response Transport: FileDownloadRedirect

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Files.PrepareDownload",
  "params": {
    "path": "<string>"
  }
}

detailsanyYesTransport specific details on how/from where to download the given file
mode"redirect" | "direct"YesDirect mode allows using Files.Download whereas redirect mode requires the usage of a different protocol
