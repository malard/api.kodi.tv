AudioLibrary

AudioLibrary.GetAlbums

Retrieve all albums from specified artist (and role) or that has songs of the specified genre

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "AudioLibrary.GetAlbums",
  "params": {
    "properties": "<Audio.Fields.Album>",
    "limits": "<List.Limits>",
    "sort": "<List.Sort>",
    "filter": "<{genreid} | {genre} | {artistid} | {artistid, roleid} | {artistid, role} | {artist} | {artist, roleid} | {artist, role} | List.Filter.Albums>",
    "includesingles": "<boolean>",
    "allroles": "<boolean>"
  }
}
