Files.SetFileDetails

Update the given specific file with the given details

Permission: UpdateData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Files.SetFileDetails",
  "params": {
    "file": "<string>",
    "media": "<Files.Media>",
    "playcount": "<Optional.Integer>",
    "lastplayed": "<Optional.String>",
    "resume": "<null | Video.Resume>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
filestringYesFull path to the file
mediaFiles.MediaYesFile type to update correct database. Currently only "video" is supported.
playcountOptional.IntegerNo
lastplayedOptional.StringNoSetting a valid lastplayed without a playcount will force playcount to 1.
resumenull | Video.ResumeNonull

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
