Addons.GetAddons

Gets all available addons

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Addons.GetAddons",
  "params": {
    "type": "<Addon.Types>",
    "content": "<Addon.Content>",
    "enabled": "<boolean | \"all\">",
    "properties": "<Addon.Fields>",
    "limits": "<List.Limits>",
    "installed": "<boolean | \"all\">"
  }
}
