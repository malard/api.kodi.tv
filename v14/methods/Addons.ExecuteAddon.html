Addons.ExecuteAddon

Executes the given addon with the given parameters (if possible)

Permission: ExecuteAddon Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Addons.ExecuteAddon",
  "params": {
    "addonid": "<string>",
    "params": "<object | array of string | string>",
    "wait": "<boolean>"
  }
}

Parameters

addonidstringYes
params

  • array of string
  • string
No""

string
