XBMC

XBMC.GetInfoLabels

Retrieve info labels about Kodi and the system. Use GUI.GetInfoLabels instead.

Deprecated. Still served, but it will be removed in the next major version of the API. The description says what to use instead.

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "XBMC.GetInfoLabels",
  "params": {
    "labels": "<array of string>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
labelsarray of string (minItems: 1)YesSee http://kodi.wiki/view/InfoLabels for a list of possible info labels

Returns

Object containing key-value pairs of the retrieved info labels
