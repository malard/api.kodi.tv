GUI

GUI.DeleteScreenshots

Deletes screenshots from the configured screenshot folder, which is otherwise the one thing a client can fill and never reclaim. Disabled unless <jsonrpc><allowscreenshotdeletion>true</allowscreenshotdeletion></jsonrpc> is set in advancedsettings.xml, and answers Unavailable while it is off: this is the only call that deletes a file from disk, and the folder it clears is wherever the viewer pointed debug.screenshotpath.

Permission: RemoveData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "GUI.DeleteScreenshots",
  "params": {
    "file": "<string>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
filestringNo""The one screenshot to delete, named as GUI.TakeScreenshot answered or as a plain file name. Every .png in the folder is deleted when omitted, whichever of them Kodi wrote. Nothing outside the folder is reachable either way.

Returns

NameTypeRequiredDefaultDescription
deletedinteger (minimum: 0)NoHow many files were deleted.

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
