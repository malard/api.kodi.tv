Addons.SetAddonEnabled

Enables/Disables a specific addon

Permission: ManageAddon Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Addons.SetAddonEnabled",
  "params": {
    "addonid": "<string>",
    "enabled": "<Global.Toggle>"
  }
}
