Files.GetDirectory

Get the directories and files in the given directory

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Files.GetDirectory",
  "params": {
    "directory": "<string>",
    "media": "<Files.Media>",
    "properties": "<List.Fields.Files>",
    "sort": "<List.Sort>",
    "limits": "<List.Limits>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
directorystringYes
mediaFiles.MediaNo"files"
propertiesList.Fields.FilesNo
sortList.SortNo
limitsList.LimitsNoLimits are applied after getting the directory content thus retrieval is not faster when they are applied.

Returns

NameTypeRequiredDefaultDescription
limitsList.LimitsReturnedYes
filesarray of List.Item.FileYes

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
