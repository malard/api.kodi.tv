AudioLibrary

AudioLibrary.Export

Exports all items from the audio library

Permission: WriteFile Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "AudioLibrary.Export",
  "params": {
    "options": "<{path} | {overwrite, images}>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
options
  • object {path}
  • object {overwrite, images}
No

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
