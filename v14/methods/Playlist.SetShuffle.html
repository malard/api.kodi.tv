Playlist

Playlist.SetShuffle

Shuffle or unshuffle the playlist, whether or not it is currently being played. The items are reordered immediately, and the state persists unless overridden by the shuffled option of Player.Open. For picture playlists (aka slideshows) shuffling is only possible while a slideshow is running and cannot be undone.

Permission: ControlPlayback Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Playlist.SetShuffle",
  "params": {
    "playlistid": "<Playlist.Id>",
    "shuffle": "<Global.Toggle>"
  }
}

Parameters
