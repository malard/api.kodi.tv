VideoLibrary.GetAvailableArt

Retrieve all potential art URLs for a media item by art type

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "VideoLibrary.GetAvailableArt",
  "params": {
    "item": "<{episodeid} | {tvshowid} | {seasonid} | {movieid} | {setid} | {musicvideoid}>",

  }
}
