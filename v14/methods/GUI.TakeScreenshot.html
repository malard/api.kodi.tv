GUI

GUI.TakeScreenshot

Takes a screenshot into the configured screenshot folder and answers with the files it wrote. Waits for the capture to be encoded, so every file it names is complete when the response arrives. Pass a returned path to Files.PrepareDownload to fetch the image. Answers Unavailable when no screenshot folder is configured.

Permission: ControlGUI Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "GUI.TakeScreenshot",
  "params": {
    "content": "<\"composite\" | \"video\" | \"both\">",
    "target": "<string>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
content"composite" | "video" | "both"No"composite"composite captures the full display output, video only the video frame, both writes two files, the video frame and the full composite, from the same rendered frame
targetstringNo""Name to write the screenshot under, which must be a plain .png file name carrying no directory: the file always goes to the configured folder, and an existing one of that name is overwritten. Names the composite, the video frame taking the matching "-video" name. Auto-numbered as screenshotNNNNN.png when omitted. A client capturing repeatedly should name a target and reuse it: the auto-numbered name accumulates files it cannot reclaim without GUI.DeleteScreenshots, costs a directory listing per call, and runs out at 65535.

Returns

NameTypeRequiredDefaultDescription
compositestringNoPath of the full display output, under special://screenshots. Absent when only the video frame was captured.
videostringNoPath of the video frame alone, under special://screenshots. Absent when only the composite was captured.

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
