VideoLibrary

VideoLibrary.Refresh

Refresh the given item in the library

Permission: UpdateData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "VideoLibrary.Refresh",
  "params": {
    "item": "<{movieid} | {setid} | {tvshowid} | {seasonid} | {episodeid} | {musicvideoid}>",
    "ignorenfo": "<boolean>",
    "refreshepisodes": "<boolean>",
    "title": "<string>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
item
  • object {movieid}
  • object {setid}
  • object {tvshowid}
  • object {seasonid}
  • object {episodeid}
  • object {musicvideoid}
YesThe library item to refresh.
ignorenfobooleanNofalseWhether or not to ignore a local NFO if present.
refreshepisodesbooleanNofalseWhether or not to refresh all episodes belonging to the item. Applies to a tv show or a season.
titlestringNo""Title to use for searching (instead of determining it from the item's filename/path).

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
