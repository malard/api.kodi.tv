VideoLibrary

VideoLibrary.SetSourceContent

Assigns a content type and scraper to a video source path, as the 'Set content' dialog does

Permission: UpdateData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "VideoLibrary.SetSourceContent",
  "params": {
    "path": "<string>",
    "content": "<\"movies\" | \"tvshows\" | \"musicvideos\" | \"none\">",
    "scraperid": "<string>",
    "scrapersettings": "<string>",
    "scanrecursive": "<boolean>",
    "usedirectorynames": "<boolean>",
    "containssingleitem": "<boolean>",
    "noupdate": "<boolean>",
    "clearmode": "<\"clear\" | \"exclude\" | \"remove\">",
    "refresh": "<boolean>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
pathstring (minLength: 1)YesPath the content binding applies to. A trailing separator is added if missing
content"movies" | "tvshows" | "musicvideos" | "none"YesContent type to bind, or "none" to clear the binding
scraperidstringNo""Addon id of the scraper. Required unless content is "none"
scrapersettingsstringNo""Scraper settings as XML. Scraper defaults are used when empty
scanrecursivebooleanNotrueScan sub folders. Ignored for tvshows and when containssingleitem is set
usedirectorynamesbooleanNofalseTake the item name from the containing folder. Ignored for tvshows
containssingleitembooleanNofalseThe path holds one item, named after the folder the scan started in
noupdatebooleanNofalseExclude the path from library updates
clearmode"clear" | "exclude" | "remove"No"clear"Only used when content is "none". "clear" unbinds the scraper, "exclude" also excludes the path from scanning, "remove" additionally deletes the items already scraped from it
refreshbooleanNofalseScan the path once the binding has been applied

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
