Playlist

Playlist.Swap

Swap items in the playlist. Does not work for picture playlists (aka slideshows).

Permission: ControlPlayback Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Playlist.Swap",
  "params": {
    "playlistid": "<Playlist.Id>",
    "position1": "<Playlist.Position>",
    "position2": "<Playlist.Position>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
playlistidPlaylist.IdYes
position1Playlist.PositionYes
position2Playlist.PositionYes

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
