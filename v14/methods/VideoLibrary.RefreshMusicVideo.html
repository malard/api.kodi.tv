VideoLibrary

VideoLibrary.RefreshMusicVideo

Refresh the given music video in the library. Use VideoLibrary.Refresh instead.

Deprecated. Still served, but it will be removed in the next major version of the API. The description says what to use instead.

Permission: UpdateData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "VideoLibrary.RefreshMusicVideo",
  "params": {
    "musicvideoid": "<Library.Id>",
    "ignorenfo": "<boolean>",
    "title": "<string>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
musicvideoidLibrary.IdYes
ignorenfobooleanNofalseWhether or not to ignore a local NFO if present.
titlestringNo""Title to use for searching (instead of determining it from the item's filename/path).

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
