Playlist

Playlist.GetPlaylistsReturns all existing playlists
Playlist.GetPropertiesRetrieves the values of the given properties
Playlist.GetItemsGet all items from playlist
Playlist.AddAdd item(s) to playlist
Playlist.InsertInsert item(s) into playlist. Does not work for picture playlists (aka slideshows).
Playlist.RemoveRemove item from playlist. Does not work for picture playlists (aka slideshows).
Playlist.ClearClear playlist
Playlist.SetRepeatSet the repeat mode of the playlist, whether or not it is currently being played. The state persists and takes effect when playback of the playlist starts, unless overridden by the repeat option of Player.Open. Does not work for picture playlists (aka slideshows).
Playlist.SetShuffleShuffle or unshuffle the playlist, whether or not it is currently being played. The items are reordered immediately, and the state persists unless overridden by the shuffled option of Player.Open. For picture playlists (aka slideshows) shuffling is only possible while a slideshow is running and cannot be undone.
Playlist.SwapSwap items in the playlist. Does not work for picture playlists (aka slideshows).

GUI

GUI.ActivateWindowActivates the given window

GUI.SetFullscreenToggle fullscreen/GUI
GUI.SetStereoscopicModeSets the stereoscopic mode of the GUI to the given mode
GUI.GetStereoscopicModesReturns the supported stereoscopic modes of the GUI
GUI.ActivateScreenSaverActivates currently used screensaver
GUI.TakeScreenshotTakes a screenshot into the configured screenshot folder and answers with the files it wrote. Waits for the capture to be encoded, so every file it names is complete when the response arrives. Pass a returned path to Files.PrepareDownload to fetch the image. Answers Unavailable when no screenshot folder is configured.
GUI.DeleteScreenshotsDeletes screenshots from the configured screenshot folder, which is otherwise the one thing a client can fill and never reclaim. Disabled unless <jsonrpc><allowscreenshotdeletion>true</allowscreenshotdeletion></jsonrpc> is set in advancedsettings.xml, and answers Unavailable while it is off: this is the only call that deletes a file from disk, and the folder it clears is wherever the viewer pointed debug.screenshotpath.
