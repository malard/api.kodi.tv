AudioLibrary

AudioLibrary.GetArtists

Retrieve all artists. For backward compatibility by default this implicitly does not include those that only contribute other roles, however absolutely all artists can be returned using allroles=true

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "AudioLibrary.GetArtists",
  "params": {
    "albumartistsonly": "<Optional.Boolean>",
    "properties": "<Audio.Fields.Artist>",
    "limits": "<List.Limits>",
    "sort": "<List.Sort>",
    "filter": "<{genreid} | {songgenreid} | {songgenreid, roleid} | {songgenreid, role} | {genre} | {songgenre} | {songgenre, roleid} | {songgenre, role} | {albumid} | {album} | {songid} | {songid, roleid} | {songid, role} | {roleid} | {role} | List.Filter.Artists>",
    "allroles": "<boolean>"
  }
}
