Input.ButtonEvent

Send a button press event

Permission: Navigate Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Input.ButtonEvent",
  "params": {
    "button": "<string>",
    "keymap": "<\"KB\" | \"XG\" | \"R1\" | \"R2\">",
    "holdtime": "<integer>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
buttonstringYesButton name
keymap"KB" | "XG" | "R1" | "R2"YesKeymap name (KB, XG, R1, or R2)
holdtimeinteger (minimum: 0)No0Number of milliseconds to simulate button hold.

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
