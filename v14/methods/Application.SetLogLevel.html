Application

Application.SetLogLevel

Changes the log level and the components with extra logging, and answers with what is now in force. Either parameter may be left out to keep its current value

Permission: ControlSystem Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Application.SetLogLevel",
  "params": {
    "level": "<null | Application.LogLevel>",
    "components": "<null | array of string>"
  }
}

Parameters

NameTypeRequiredDefaultDescription
levelnull | Application.LogLevelNonull
componentsnull | array of stringNonullthe names of the components to enable extra logging for; every other component is disabled, and an empty array disables component logging

Returns

Application.LogLevel.Value

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
