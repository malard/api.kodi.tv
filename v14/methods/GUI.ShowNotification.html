GUI

GUI.ShowNotification

Shows a GUI notification

Permission: ControlGUI Transport: Response

Request

Show a notification in the Kodi GUI

{
  "jsonrpc": "2.0",
  "id": 6,
  "method": "GUI.ShowNotification",
  "params": {
    "title": "Library update",
    "message": "The video library scan has finished",
    "image": "info",
    "displaytime": 5000
  }
}

Response

{
  "jsonrpc": "2.0",
  "id": 6,
  "result": "OK"
}

Parameters

NameTypeRequiredDefaultDescription
titlestringYes
messagestringYes
image"info" | "warning" | "error" | stringNo""
displaytimeinteger (minimum: 1500)No5000The time in milliseconds the notification will be visible

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
