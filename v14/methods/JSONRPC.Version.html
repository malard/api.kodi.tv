JSONRPC

JSONRPC.Version

Retrieve the JSON-RPC protocol version.

Permission: ReadData Transport: Response

Request

Retrieve the JSON-RPC protocol version

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "JSONRPC.Version"
}

Response

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "version": {
      "major": 13,
      "minor": 15,
      "patch": 0
    }
  }
}

Returns

NameTypeRequiredDefaultDescription
versionobject {major, minor, patch}Yes

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
