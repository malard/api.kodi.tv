Player.GetProperties

Retrieves the values of the given properties

Permission: ReadData Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Player.GetProperties",
  "params": {
    "playerid": "<Player.Id>",
    "properties": "<array of Player.Property.Name>"
  }
}
