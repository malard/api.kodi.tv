Playlist

Playlist.SetRepeat

Set the repeat mode of the playlist, whether or not it is currently being played. The state persists and takes effect when playback of the playlist starts, unless overridden by the repeat option of Player.Open. Does not work for picture playlists (aka slideshows).

Permission: ControlPlayback Transport: Response

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Playlist.SetRepeat",
  "params": {
    "playlistid": "<Playlist.Id>",
    "repeat": "<Player.Repeat | \"cycle\">"
  }
}

Parameters

NameTypeRequiredDefaultDescription
playlistidPlaylist.IdYes
repeatPlayer.Repeat | "cycle"Yes

Returns

string

Errors

Any method can return the standard errors; -32602 (Invalid params) carries structured error.data naming the offending parameter.
