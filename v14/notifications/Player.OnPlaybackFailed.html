Player

Player.OnPlaybackFailed

Playback of a media item was requested but did not happen. Playback starts asynchronously, so a request that was answered successfully can still fail afterwards.

Transport: WebSocket / TCP only

Server-initiated push message; it is never delivered over HTTP and carries no id member.

Message

{
  "jsonrpc": "2.0",
  "method": "Player.OnPlaybackFailed",
  "params": {
    "sender": "<string>",
    "data": "<{item, reason}>"
