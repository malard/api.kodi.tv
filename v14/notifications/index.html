Notifications

45 server-initiated notifications, delivered over the WebSocket and raw TCP transports only.

Player Playlist AudioLibrary VideoLibrary System Application Input GUI Settings

Player

Player.OnPlayPlayback of a media item has been started or the playback speed has changed. If there is no ID available extra information will be provided.
Player.OnResumePlayback of a media item has been resumed. If there is no ID available extra information will be provided.
Player.OnAVStartPlayback of a media item has been started and first frame is available. If there is no ID available extra information will be provided.
Player.OnAVChangeAudio- or videostream has changed. If there is no ID available extra information will be provided.
Player.OnPausePlayback of a media item has been paused. If there is no ID available extra information will be provided.
Player.OnStopPlayback of a media item has been stopped. If there is no ID available extra information will be provided.
Player.OnPlaybackFailedPlayback of a media item was requested but did not happen. Playback starts asynchronously, so a request that was answered successfully can still fail afterwards.
Player.OnSpeedChangedSpeed of the playback of a media item has been changed. If there is no ID available extra information will be provided.
Player.OnSeekThe playback position has been changed. If there is no ID available extra information will be provided.
Player.OnPropertyChangedA property of the playing items has changed.

Playlist

Playlist.OnAddA playlist item has been added.
Playlist.OnRemoveA playlist item has been removed.
Playlist.OnClearA playlist item has been cleared.
Playlist.OnPropertyChangedA property of the playlist has changed. Unlike Player.OnPropertyChanged this is also sent when the playlist is not currently being played.

AudioLibrary

AudioLibrary.OnUpdateAn audio item has been updated.
AudioLibrary.OnRemoveAn audio item has been removed.
AudioLibrary.OnScanStartedAn audio library scan has started.
AudioLibrary.OnScanFinishedScanning the audio library has been finished.
AudioLibrary.OnCleanStartedAn audio library clean operation has started.
AudioLibrary.OnCleanFinishedThe audio library has been cleaned.
AudioLibrary.OnExportAn audio library export has finished.

VideoLibrary

VideoLibrary.OnUpdateA video item has been updated.
VideoLibrary.OnExportA video library export has finished.
VideoLibrary.OnRemoveA video item has been removed.
VideoLibrary.OnScanStartedA video library scan has started.
VideoLibrary.OnScanFinishedScanning the video library has been finished.
VideoLibrary.OnCleanStartedA video library clean operation has started.
VideoLibrary.OnCleanFinishedThe video library has been cleaned.
VideoLibrary.OnRefreshThe video library has been refreshed and a home screen reload might be necessary.

System

System.OnQuitKodi will be closed.
System.OnRestartThe system will be restarted.
System.OnSleepThe system will be suspended.
System.OnWakeThe system woke up from suspension.
System.OnLowBatteryThe system is on low battery.

Application

Application.OnVolumeChangedThe volume of the application has changed.

Input

Input.OnInputRequestedThe user is requested to provide some information.
Input.OnInputFinishedThe user has provided the requested input.

GUI

GUI.OnScreensaverActivatedThe screensaver has been activated.
GUI.OnScreensaverDeactivatedThe screensaver has been deactivated.
GUI.OnDPMSActivatedEnergy saving/DPMS has been activated.
GUI.OnDPMSDeactivatedEnergy saving/DPMS has been deactivated.
GUI.OnSkinUnloadingThe current skin is about to be unloaded.
GUI.OnSkinLoadedA skin has been loaded.
GUI.OnSkinLoadFailedA skin failed to load.

Settings

Settings.OnLevelChangedThe setting level in force has changed. The profile's settings lock can lower it without the viewer asking for it.
